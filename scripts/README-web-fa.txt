مدیا یار — نسخه‌ی وب / PWA (1.2.0)
=================================

اجرا روی کامپیوتر خودتان:
  node serve-web.js web 8080      ← سپس در مرورگر: http://localhost:8080
انتشار روی اینترنت: محتوای پوشه‌ی web را روی هر هاست استاتیک با HTTPS بگذارید
(GitHub Pages، Netlify، Cloudflare Pages، Vercel و…). بعد از اولین بار، برنامه آفلاین هم کار می‌کند
و از منوی مرورگر یا دکمه‌ی «نصب برنامه» به‌صورت اپلیکیشن نصب می‌شود.
ساخت APK اندروید: راهنمای WEB-PWA-APK.md (Capacitor یا TWA).

همه‌ی پردازش روی دستگاه کاربر انجام می‌شود (FFmpeg به WebAssembly)؛ هیچ فایلی آپلود نمی‌شود.

ضبط صفحه در نسخه‌ی وب:
  • «کل صفحه» (پیش‌فرض): مرورگر پنجره‌ی انتخاب صفحه را نشان می‌دهد؛ «کل صفحه» را انتخاب کنید.
  • «انتخاب محدوده»: بعد از اشتراک صفحه، روی پیش‌نمایش با ماوس/انگشت کادر می‌کشید.
  • صدا: میکروفون، صدای سیستم (در پنجره‌ی مرورگر «اشتراک صدای سیستم» را روشن کنید؛ کروم
    روی ویندوز) یا هر دو.
  • پایان ضبط: دکمه‌ی «پایان و ذخیره» یا «توقف اشتراک‌گذاری» مرورگر.
  • ضبط صفحه در مرورگرهای موبایل پشتیبانی نمی‌شود (در این حالت این بخش پنهان است).

محل ذخیره:
  • کروم/اج دسکتاپ: برای هر خروجی پنجره‌ی «ذخیره در» باز می‌شود (پوشه و نام قابل انتخاب).
  • مرورگرهای دیگر: نام فایل پرسیده می‌شود و در پوشه‌ی دانلودهای مرورگر ذخیره می‌شود.
  • چند فایل: «پوشه‌ی دانلودها» (پیش‌فرض) یا «پوشه‌ی دلخواه» (در کروم/اج).

محدودیت‌های نسخه‌ی وب نسبت به ویندوز: WEBM با VP8، بدون H.265 و AMR، سرعت کمتر از نسخه‌ی
دسکتاپ، دریافت حدود ۳۰ مگابایت موتور در اولین استفاده.
